# Kanon richten in graden – implementatieplan (ombouw)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kanon = 90` richt het kanon (0/90/180/270), `robot = schiet` schiet die kant op; het kanon is zichtbaar op het veld en in de statuskaart.

**Architecture:** Dit bouwt de branch `schietrichting` om van `robot = schiet(90)` naar een apart commando `kanon = …` (zie spec §1 en §7). De parser krijgt `Aim(graden)` en sjabloon `kanon=#`; `Shoot` wordt weer leeg. `Speler.kanon` bewaart de hoek; `_schiet` gebruikt die. De kogelbaan-weergave (verticaal) uit de vorige versie blijft. Nieuw in de weergave: `Cel.kanon` (schermrichting), een driehoekje in het robotvakje, `🔫 90°` in de statuskaart en een logregel.

**Tech Stack:** Python 3.12+, FastAPI/Jinja2, pytest via `uv run pytest` (nooit pip/venv). Spec: `docs/superpowers/specs/2026-09-21-schietrichting-design.md`. Branch: `schietrichting` (HEAD `0369a50`, 206 tests groen).

```python
def kanonrichting(speler: Speler, ik: int) -> str:
    """Waar het kanon van `speler` op het scherm van kijker `ik` heen wijst. 90 en 270 zijn
    voor iedereen omhoog/omlaag; 0 en 180 zijn 'vooruit'/'achteruit', en op ieders scherm
    kijkt de eigen robot naar rechts en die van de ander naar links."""
    if speler.kanon == 90:
        return "omhoog"
    if speler.kanon == 270:
        return "omlaag"
    eigen = speler.nummer == ik
    naar_rechts = eigen if speler.kanon == 0 else not eigen
    return "rechts" if naar_rechts else "links"
```
